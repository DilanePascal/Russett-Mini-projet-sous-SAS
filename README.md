"# Russett-Projet-sous-SAS" 

Contexte et objectf : L’étude analyse la base de données de Russett (1964), présentée dans Gifi (1990), qui regroupe trois grands blocs d’information : les inégalités agricoles, le développement industriel et l’instabilité politique. Le travail, réalisé sous SAS, vise à explorer les relations entre ces trois dimensions à travers des regroupements, des statistiques descriptives et des représentations graphiques.

L’objectif principal est de vérifier l’hypothèse suivante :

« Il est difficile pour un pays d’échapper à la dictature lorsque ses inégalités agricoles sont supérieures à la moyenne et son développement industriel inférieur à la moyenne. »

. Sources des données : L’étude utilise la base de données Russett (1964), telle que présentée dans Gifi (1990).
Cette base regroupe des informations socio‑économiques et politiques sur plusieurs pays
